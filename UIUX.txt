# UI / UX Design Specification

## Weekly Football Stats Tracker

Version 1.0

---

# 1. Design Principles

The application is designed around **Speed**.

The organizer should never spend more time operating the app than watching the game.

Every common action should require:

* One tap
* Large touch targets
* Minimal typing

Primary design goals:

* Mobile First
* Dark Theme
* One Hand Usage
* Fast Navigation
* Real-time Updates
