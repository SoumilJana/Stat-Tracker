# System Architecture Document (SAD)

## Weekly Football Stats Tracker

Version 1.0

---

# 1. Overview

The Weekly Football Stats Tracker is a modern web application designed with a modular architecture. The system separates presentation, business logic, and data storage to ensure scalability, maintainability, and future integrations.

Primary objectives:

* Fast goal recording
* Reliable data storage
* Automatic statistics
* Expandability for AI and messaging platforms

# 6. Request Flow

Example

User taps

```text
⚽ Soumil
```

↓

Frontend sends

POST /events/goal

↓

Backend validates

* Active session exists
* Player belongs to current team
* Session not ended

↓

Database stores event

↓

Statistics recalculated

↓

Updated score returned

↓

UI updates instantly

---
